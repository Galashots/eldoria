# Input-feel hotfix evidence (2026-08-05)

Zoom and iso-speed evidence is captured at the iPad reference viewport (1194 x 834 CSS pixels, DPR 2):

- `joystick-*.png` and `joystick-evidence.json` show the dynamic joystick at two normal bounded-zone positions and one edge-clamped position.
- `speed-topdown-30-frames.png` and `speed-iso-30-frames.png` show the same 30 fixed update frames, with the iso-only speed multiplier applied only in iso.
- `double-tap-before.png` / `double-tap-after.png` and `zoom-speed-evidence.json` record the rapid-tap scale check.

The deterministic assertions live in `tools/zoom-speed-test.mjs` and `tools/adaptive-joystick-test.mjs`; the screenshots are generated by the matching capture tools.

For iPad feel A/B, `?fixedJoystick=1` persists the original fixed 140px corner
joystick (center-origin, always visible). `?fixedJoystick=0` clears that opt-out
and restores adaptive spawn-at-touch placement.
